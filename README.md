# Sanjay Kumar — Engineering Portfolio

Portfolio source for **https://sanjay81.github.io**.

A lightweight, responsive static site introducing my embedded test automation, DevSecOps, test infrastructure and AI-assisted quality engineering work.

## Preview locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish using GitHub Pages

After merging this branch into `main`, open repository **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Content review before publication

- Verify all biography, experience and language claims.
- Add downloadable English and German resumes when approved; do not link to missing files.
- Add professional LinkedIn URL once verified.
- Replace illustrative project motifs with screenshots or architecture diagrams when available.
- Expand project summaries into individual case studies over time.

No analytics, cookies, contact forms or external frontend dependencies are used.
