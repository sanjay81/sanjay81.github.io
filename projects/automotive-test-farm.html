Linux test infrastructure · Proof of concept

Automotive Test Infrastructure Automation

A simulated two-host test farm demonstrating Ansible provisioning, artifact integrity, mock ECU flashing, validation and CI.

Technology
AnsiblePythonDockerLinuxGitHub Actions
Inspect source on GitHub ↗

The engineering problem

Test hosts need repeatable configuration, verified artifacts, automated checks and safe maintenance patterns.

Architecture / data flow

GitHub Actions / operator → Ansible playbooks → 2 Ubuntu Docker hosts → artifact SHA-256 validation → simulated flash report → JUnit validation reports

Implementation

  • Provision two containerised Ubuntu hosts with Ansible roles.
  • Deploy a harmless firmware fixture and check SHA-256 consistency.
  • Run a simulated flashing process and per-host validation with JUnit output.
  • Model serial maintenance with pre/post health checks and fail-fast behavior.

Verification and results

The README reports successful playbook syntax checks, offline linting, Python compilation and four unit tests in the inspected workspace. Docker integration was not executed there because Docker daemon access was denied.

Scope and limitations

No physical ECU flashing, no production OpenStack management and no automatic rollback. Full Docker-backed integration must be verified on a capable runner.
